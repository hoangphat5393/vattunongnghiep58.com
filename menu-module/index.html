Menu desktop có dropdown cấp 2 (hover + nút mũi tên, class is-open) giống layouts/header.blade.php; script js/desktop-nav-dropdown.js đồng bộ với resources/js/custom.js. Checklist triển khai (copy folder)

  1. Copy cả thư mục menu-module/ — gồm js/tailwind-4.2.js, css/menu-custom.css, assets/, index.html.
  2. Đổi nội dung trong <main> theo site đích; giữ header + overlay + drawer nếu chỉ cần menu.
  3. Logo trong module: assets/images/logo.svg. Production: file public/upload/images/logo/logo.png + cấu hình CSDL.
  4. Cuối <body>: tailwind-4.2.js → khối text/tailwindcss → mobile-menu.js → desktop-nav-dropdown.js → menu.js.
  5. Laravel: dùng Blade header + Vite app.css; rule z-index #mobile-menu-overlay / #mobile-menu trong app.css.
