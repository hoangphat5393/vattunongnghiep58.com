# Laravel 13 compatibility forks

Các package trong thư mục này là bản fork nội bộ (chỉ sửa `composer.json` constraint `^13.0`) vì upstream chưa khai báo hỗ trợ Laravel 13.

| Package                    | Upstream | Fork version |
| -------------------------- | -------- | ------------ |
| `ckfinder-laravel-package` | v5.0.2   | 5.0.3        |
| `shoppingcart`             | v2.0.0   | 2.0.1        |
| `laravel-shortcodes`       | v1.5     | 1.5.1        |

Khi upstream phát hành bản hỗ trợ L13 chính thức, có thể xóa fork và quay lại Packagist.
